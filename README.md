# Учёт личных финансов

Консольное приложение на Java: доходы и расходы по категориям, бюджеты, статистика,
оповещения о перерасходе и переводы между пользователями. Данные хранятся в памяти, а при
выходе сохраняются в JSON-файлы.

## Запуск

Нужен JDK 17 или новее.

```bash
./gradlew run -q --console=plain
```

Данные сохраняются в папку `data`.

## Команды

| Команда | Что делает |
|---|---|
| `register <логин> <пароль>` | регистрация |
| `login <логин> <пароль>` | вход |
| `income <категория> <сумма> [дата]` | добавить доход |
| `expense <категория> <сумма> [дата]` | добавить расход |
| `budget <категория> <сумма>` | установить или изменить бюджет |
| `remove-budget <категория>` | убрать бюджет |
| `add-category <название> <income\|expense>` | создать категорию |
| `rename-category <старое> -> <новое>` | переименовать категорию |
| `delete-category <название>` | удалить категорию без операций |
| `categories` | категории, бюджеты и остатки |
| `balance` | баланс |
| `stats [--from дата] [--to дата]` | сводка по доходам, расходам и бюджетам |
| `stats <кат1>, <кат2>` | подсчёт по выбранным категориям |
| `history [--from дата] [--to дата]` | список операций |
| `report <файл>` | сохранить сводку в файл |
| `transfer <логин> <сумма>` | перевод другому пользователю |
| `export <файл.csv>` / `import <файл.csv>` | выгрузка и загрузка операций |
| `logout` / `exit` | выход с сохранением |
| `help` | справка |

Дата в формате `2026-11-20`. Категория может содержать пробелы: `expense Коммунальные услуги 3000`.

## Пример (вывод сокращён)

```text
> register nikolay pass1
> login nikolay pass1
nikolay> income Зарплата 60000
nikolay> expense Еда 800
nikolay> expense Коммунальные услуги 3000
nikolay> budget Коммунальные услуги 2500
  Бюджет «Коммунальные услуги» установлен: 2,500.00
[!] Превышен бюджет «Коммунальные услуги»: потрачено 3,000.00 из 2,500.00, перерасход 500.00
nikolay> stats Еда, Такси
  Категория              Тип      Операций          Сумма
  Еда                    расход          1         800.00
  Категория «Такси» не найдена
nikolay> exit
Кошелёк сохранён.
```

Оповещения (`[!]`) появляются при 80% бюджета, превышении бюджета, когда расходы больше
доходов и при нулевом балансе.

## Структура

```text
core/model        User, Wallet, Category, Transaction
core/service      логика: вход, операции и бюджеты, статистика, оповещения, переводы
core/repository   интерфейсы хранилищ
infra             сохранение в JSON и CSV
cli               консоль: команды и вывод
```

Логика не зависит от консоли и от формата файлов: консоль только вызывает сервисы, а сервисы
работают с хранилищами через интерфейсы.

Кошелёк загружается из файла при входе и сохраняется при `logout` и `exit`. Каждому
пользователю соответствует свой файл `data/wallets/<логин>.json`.

## Тесты

```bash
./gradlew test
```

60 тестов: сервисы, сохранение в файлы, разбор команд и сквозные сценарии через консоль.
`./gradlew build` дополнительно проверяет форматирование кода (Spotless). На каждый push
сборка запускается в GitHub Actions.

## Допущения

- Категория создаётся автоматически при первой операции.
- Бюджет задаётся только для категорий расходов и действует без срока.
- Перевод возможен, только если хватает денег. Обычный расход разрешён всегда, но при
  перерасходе выводится предупреждение.
